✅ Task Master: To-Do App

Una aplicación web de gestión de tareas diseñada para mejorar la productividad. Este proyecto se centra en la interactividad del usuario y la gestión dinámica de elementos de lista mediante JavaScript.

🌟 Funcionalidades Clave

Crear Tareas: Añade nuevas tareas de forma instantánea a la lista.
Estado de Tarea: Marca tareas como completadas con un simple clic para llevar un control visual.
Eliminación Dinámica: Borra tareas individuales de la lista de forma permanente.
Interfaz Limpia: Diseño minimalista enfocado en la usabilidad y legibilidad.

🛠️ Stack Tecnológico

HTML5: Estructura de la lista y formularios de entrada.
CSS3: Estilos personalizados para tareas completadas (tachado) y botones de acción.
JavaScript (Vanilla):
Manipulación del DOM: Creación de nodos (createElement) y eliminación (remove).
Event Listeners: Manejo de clics y envío de formularios.
Lógica de Estados: Alternancia de clases CSS para el marcado de tareas.
